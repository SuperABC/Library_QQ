# 考试辅助网站 · 总需求

## 1. 目标
为备考用户提供：历年真题查阅、模拟题查阅、每日自动出卷练习。内容不对所有人开放：历年真题公开，其余需要管理员发放的验证码。同时为管理员提供题库维护与权限管理工具。**不使用数据库**，全部数据以文件保存。

## 2. 页面清单

| 页面 | 路径 | 权限 | 说明文档 |
|---|---|---|---|
| 主页 | `/` | 公开 | [pages/home.md](pages/home.md) |
| 历年真题 | `/past.html` | 公开 | [pages/past-papers.md](pages/past-papers.md) |
| 全部模拟题 | `/mock.html` | 验证码 | [pages/mock-questions.md](pages/mock-questions.md) |
| 每日一练 | `/daily.html` | 验证码 | [pages/daily-quiz.md](pages/daily-quiz.md) |
| 输入验证码 | `/unlock.html` | 公开 | 见 home.md |
| 题库维护（管理） | `/admin/bank.html` | 管理员 | [pages/admin-bank.md](pages/admin-bank.md) |
| 权限管理（管理） | `/admin/access.html` | 管理员 | [pages/admin-access.md](pages/admin-access.md) |

## 3. 功能需求
1. 主页可跳转到三个子页面，并显示当前是否已解锁。
2. 历年真题：公开浏览 PDF（在线预览/下载）。
3. 全部模拟题：需验证码；包含模拟试卷 PDF 和结构化模拟简答题。
4. 每日一练：系统每天自动出一份简答题卷，**服务端生成后保存为文件，当天所有用户拿到同一份，不重复生成**；用户作答后对照参考答案，并自评打分；成绩保存在本地浏览器。
5. 题库维护工具：上传/改名/删除 PDF；录入、编辑、删除、批量导入简答题；重新生成今日试卷。
6. 权限管理工具：生成验证码（可设有效期、绑定 IP 上限、备注，支持批量），吊销/恢复、重置绑定、删除。

## 4. 权限设计（无数据库）
- 管理员在后台生成验证码，存于 `data/codes.json`（明文存储，便于管理员随时查看再发给用户；该文件只在服务器上，不会被 Web 访问）。
- 用户在 `/unlock.html` 提交验证码。服务端校验并**把当前 IP 绑定到该码**（超过 `maxIps` 则拒绝），然后下发 HttpOnly 签名 cookie（HMAC-SHA256，含验证码 ID、IP、过期时间）。
- 每次访问受保护接口，服务端同时校验：cookie 签名有效、cookie 内 IP 等于当前 IP、验证码未吊销、未过期、IP 在绑定列表中。因此吊销/过期/重置绑定**立即生效**。
- 与最初设想的差异：不再由前端传“验证码密文”。在 HTTPS 下传输本身已加密，前端哈希后等同于一个新口令，没有额外安全收益；改用服务端签名 cookie，更安全也更简单。**生产环境必须使用 HTTPS**。
- 防暴力破解：同一 IP 15 分钟内失败 8 次后锁定；管理员登录同理（5 次）。
- 局限：IP 变化（手机切换网络）会失效，需管理员“重置绑定”或调大 `maxIps`；同一 NAT 出口下的人共享 IP。

## 5. 题库设计
- **PDF**：`data/pdfs/past|mock/<id>.pdf`，元数据在 `data/bank.json` 的 `papers`。
- **结构化简答题**：`bank.json` 的 `questions`，字段：`id / stem 题干 / answer 参考答案 / keywords 关键词 / source 来源 / from(past|mock)`。每日出卷从**全部**简答题抽取；`from=mock` 的会在“全部模拟题”页展示；真题类题目只用于每日出卷，不对外直接列出。
- 为何不用数据库：数据量小（几百到几千题）、单管理员写入，JSON 文件 + 原子写入足够，且可直接备份/版本管理。PDF 内容暂不自动解析为题目（排版不稳定），需在后台录入或批量导入（支持 JSON 与 Excel 粘贴的制表符格式）。如日后题量/并发显著增长，可替换 `server/bank/store.js` 为 SQLite，接口不变。

## 6. 每日出卷
- 以日期（`YYYY-MM-DD`）为随机种子，从题库抽取 `DAILY_COUNT`（默认 5）题，尽量避开最近 7 天出过的题。
- 生成时机：服务启动时、每天跨日时（每分钟检查），以及当天首次请求时（兜底）。结果写入 `data/daily/<日期>.json`，已存在则不再生成。
- 答题前接口不返回参考答案；点击“提交”才取得答案。
- 评测：题目全是简答题，不做机器打分。展示参考答案，并统计用户答案命中的关键词，由用户对每题自评（没答出 0 / 部分正确 0.5 / 基本正确 1）。

## 7. 技术栈与部署
- Node.js ≥ 20 + Express；前端为原生 HTML/CSS/JS，无构建步骤。
- 启动：`npm install && npm start`，详见根目录 [README.md](../README.md)。
- 配置（环境变量）：`PORT`、`HOST`、`DATA_DIR`、`ADMIN_PASSWORD`、`ADMIN_ALLOW_REMOTE`、`TRUST_PROXY`、`DAILY_COUNT`。
- 管理后台默认**仅限本机访问**（再叠加管理员密码）；部署到服务器后如需远程管理，设置 `ADMIN_ALLOW_REMOTE=1`，并务必使用 HTTPS 与强密码。
- 在反向代理（Nginx 等）后面必须设置 `TRUST_PROXY`（如 `1`），否则取到的都是代理 IP，IP 绑定会失效。

## 8. 版本范围
**v1（本版）**：上述全部功能。
**暂不做**：PDF 自动抽题、AI 打分、用户账号体系、答题记录的服务端汇总。

## 9. 测试
`npm test` 运行端到端冒烟测试（临时数据目录、模拟多 IP），覆盖：管理员登录、PDF 上传、公开/受保护访问、验证码 IP 绑定/吊销/重置、每日试卷稳定性与答案隔离。
