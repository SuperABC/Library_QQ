# 权限管理工具（`/admin/access.html`）· 管理员

## 设计
- 验证码保存在 `data/codes.json`（不使用数据库）。每条记录：ID、验证码、备注、创建时间、到期时间、最多绑定 IP 数、已绑定 IP 列表、是否吊销。
- 验证码格式 `XXXX-XXXX`，字符集去掉易混淆的 0/O、1/I/L。
- 用户校验通过后，服务端把用户 IP 加入该码的已绑定列表并下发签名 cookie。之后每次访问都重新核对码状态与 IP，所以改动即时生效。
- 登录与网络限制同 [题库维护](admin-bank.md)。
- 文件：`admin/access.html`，接口 `/admin/api/codes`。

## 功能
- **生成**：备注（给谁用）、有效天数（空=永久）、最多绑定 IP 数（默认 1）、一次生成数量（≤50）。
- **列表**：验证码、备注、状态（有效/已过期/已吊销）、到期时间、已绑定 IP / 上限。
- **复制**：一键复制验证码发给用户。
- **重置绑定**：清空已绑定 IP。用户换网络后使用。已登录的旧 IP 立即失效。
- **吊销/恢复**：临时停用某验证码。
- **删除**：永久删除，立即失效。

## 使用
1. 登录后台 → 权限管理。
2. 填写备注与有效期，点“生成”，复制验证码发给用户。
3. 用户反馈“绑定到其他网络”时，点该行“重置绑定”，让用户重新输入验证码。
4. 发现验证码被外传：点“吊销”或“删除”，再给用户生成新码。

## 注意
- 绑定依据的是服务端看到的客户端 IP。反向代理后必须配置 `TRUST_PROXY`，否则所有用户 IP 相同。
- `codes.json` 含明文验证码，务必不要放进 Web 目录或提交到 Git（`data/` 已被 `.gitignore` 忽略）。
