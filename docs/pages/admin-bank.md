# 题库维护工具（`/admin/bank.html`）· 管理员

## 设计
- 入口 `/admin/`，输入管理员密码登录（密码在 `data/secrets.json`，首次启动时控制台会打印；也可用环境变量 `ADMIN_PASSWORD` 指定）。登录有效 12 小时，且与登录 IP 绑定。
- 默认只允许本机访问 `/admin`；远程管理需设置 `ADMIN_ALLOW_REMOTE=1`。
- 三个标签页：PDF 试卷 / 简答题 / 每日试卷。数据读写 `data/bank.json` 和 `data/pdfs/`，改动立即对前台生效。
- 文件：`admin/index.html`、`admin/bank.html`，接口前缀 `/admin/api`。

## 功能
### PDF 试卷
- 上传：选择类型（历年真题=公开 / 模拟题=需验证码）、标题、年份、PDF 文件（≤100MB，会校验文件头是否为 PDF）。
- 列表：查看、改名/改年份、删除（同时删除磁盘文件）。

### 简答题
- 添加/编辑/删除单题：题干、参考答案、关键词（逗号分隔）、来源、归属（真题/模拟题）。
- 批量导入：
  - JSON 数组：`[{"stem":"题干","answer":"答案","keywords":["关键词"],"source":"2022真题","from":"past"}]`
  - 制表符文本：每行 `题干⇥答案⇥关键词⇥来源`，可直接从 Excel 复制粘贴；导入时选择统一归属。
  - 题干或答案为空的行自动跳过。
- 搜索/按归属筛选。

### 每日试卷
- 显示今天日期、每日题数、题库总数、已生成份数。
- “重新生成今日试卷”：删除今天的文件并重新抽题（例如刚补充了题库）。

## 使用
1. 本机运行 `npm start`，打开 `http://localhost:3000/admin/` 登录。
2. 先上传 PDF，再在“简答题”里把题目录入或批量导入（每日一练依赖这些结构化题目）。
3. 到前台页面核对显示是否正确。

## 备份
整个 `data/` 目录就是全部数据，复制即备份。
