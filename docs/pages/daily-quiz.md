# 每日一练（`/daily.html`）· 需验证码

## 设计
- 服务端每天出一份简答题卷（默认 5 题），保存为 `data/daily/<日期>.json`。同一天所有用户拿到同一份，访问时直接读取，**不会重复生成**。
- 出卷规则：以日期为随机种子从全部简答题中抽取，尽量避开最近 7 天出过的题；题库不足时放宽。生成时机：服务启动、每天跨日（每分钟检查一次）、当天首次请求（兜底）。
- 答题前接口 `GET /api/daily/:date` 只返回题干，不含答案；提交后才请求 `GET /api/daily/:date/answers`。
- 日期下拉框可切换到过往任一天重做；不能访问未来日期。
- 作答内容、自评与得分保存在当前浏览器 `localStorage`（键 `daily:<日期>`），不上传服务器；换浏览器/清缓存会丢失。
- 文件：`public/daily.html`。

## 功能
- 每题一个文本框作答，输入时自动保存草稿。
- “提交并对照参考答案”：展示每题参考答案（关键词高亮）及“关键词命中 x / y”（根据你的答案文本是否包含关键词统计，仅作参考）。
- 自评：每题选择“没答出(0) / 部分正确(0.5) / 基本正确(1)”，页顶汇总得分。
- “重新作答”清空当天记录重来。
- “历史记录”表格列出已完成日期的自评得分。

## 使用
1. 主页点击“每日一练”（首次需验证码）。
2. 先凭记忆作答，写完点“提交并对照参考答案”。
3. 对照答案给每题自评，查看总分。
4. 想补做以前的卷子，在日期下拉框里选日期。

## 说明
- 简答题没有标准的机器判分，关键词命中只是辅助；最终分数由自评决定。
- 管理员可在 [题库维护](admin-bank.md) 的“每日试卷”标签重新生成今日试卷（会覆盖当天已有试卷）。
