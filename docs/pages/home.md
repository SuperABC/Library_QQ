# 主页（`/`）与验证码页（`/unlock.html`）

## 设计
- 单页三张入口卡片：历年真题（公开）、全部模拟题、每日一练。
- 页头显示解锁状态徽章（已解锁/未解锁）；已解锁时出现“退出解锁”按钮。
- 受保护入口的徽章随状态在“需验证码/已解锁”之间切换。
- 文件：`public/index.html`、`public/unlock.html`；解锁状态来自 `GET /api/auth/status`。

## 功能
- 路由到三个子页面。
- 未解锁用户点击受保护页面时，页面的接口返回 401，前端自动跳转 `/unlock.html?next=<原页面>`；解锁成功后回到原页面。
- 验证码页：输入验证码（不区分大小写，`-` 和空格可省略）→ 提交到 `POST /api/auth/unlock`。错误会提示原因：不正确 / 已吊销 / 已过期 / 已绑定到其他网络。
- “退出解锁”调用 `POST /api/auth/logout` 清除 cookie（不会解除服务端的 IP 绑定）。

## 使用
1. 向管理员索取验证码。
2. 打开主页，点击“全部模拟题”或“每日一练”，按提示输入验证码。
3. 解锁后 30 天内（或到验证码过期前）在同一网络下无需再次输入。
4. 换网络后失效，请联系管理员重置绑定。
