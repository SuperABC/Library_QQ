# 全部模拟题（`/mock.html`）· 需验证码

## 设计
- 两个标签页：
  - **模拟试卷（PDF）**：列表 + 在线预览/下载，与历年真题页相同的交互。
  - **模拟题目（简答）**：结构化题目列表，每题默认折叠参考答案，答案中的关键词高亮；搜索框可按题干/答案/标签过滤；“全部展开答案”按钮。
- 文件：`public/mock.html`；接口 `GET /api/papers/mock`、`GET /api/files/mock/:id`、`GET /api/questions/mock`，全部经过 `requireAccess` 校验。
- 页面本身是静态 HTML，不含任何题目内容；未授权时接口返回 401，前端跳转到验证码页。

## 功能
- 浏览/预览/下载模拟试卷 PDF。
- 查看、搜索模拟简答题与参考答案。

## 使用
1. 主页点击“全部模拟题”，首次需要输入验证码。
2. “模拟试卷”标签：点“在线查看”或“下载”。
3. “模拟题目”标签：先自己想答案，再点“参考答案”核对；可用搜索框按知识点查找。

## 维护
- PDF：在 [题库维护](admin-bank.md) 上传，类型选“模拟题”。
- 题目：在“简答题”标签添加，归属选“模拟题”（归属为“真题”的题目不会在本页展示，只用于每日出卷）。
