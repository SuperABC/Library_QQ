# 历年真题（`/past.html`）· 公开

## 设计
- 列表页：每份试卷一张卡片，显示标题、年份、文件大小，按年份倒序。
- 顶部搜索框，按标题/年份实时过滤。
- 点击“在线查看”在页面下方内嵌 PDF 预览（浏览器自带 PDF 阅读器）；“下载”直接下载。
- 文件：`public/past.html`；接口 `GET /api/papers/past`、`GET /api/files/past/:id`（`?download=1` 为下载）。
- 无需验证码。接口只会返回 `kind=past` 的试卷，用模拟题的 ID 访问会得到 404。

## 功能
- 查看列表、搜索、在线预览、下载。

## 使用
1. 主页点击“历年真题”。
2. 搜索或浏览列表，点击“在线查看”阅读，或“下载”保存。

## 维护
由管理员在 [题库维护](admin-bank.md) 中上传（类型选“历年真题”）。
